# Security

This portfolio is a static frontend application.

## Reporting a security issue

If you find a security problem, please contact:

**phatnguyen03022001@gmail.com**

Please do not publish sensitive details in a public issue before the problem is reviewed.

## Security rules

- Do not commit private API keys or service secrets.
- Keep contact integrations free of sensitive credentials in client code.
- Keep dependencies updated.
- Validate external links and user-controlled input before adding new integrations.
